# 典型使用方式

以下是可复制的任务请求，不代表已执行或已获得结果。

## 从零开始

> 使用 $export-buyer-discovery。附产品目录和工厂介绍。先整理供货条件，比较5—8个有依据的候选市场，给推荐及未知项。我选定市场后，再找本批100家新增合格潜在公司，核采购人和公开商务联系方式。不发送信息。

## 已经指定市场

> 使用 $export-buyer-discovery。目标市场已定为我指定的国家，先检查产品与供货条件是否有关键障碍，不擅自换国家。按预算和时间边界找新公司，与我附的旧库去重，保留来源和未核原因。

## 已有主表，继续补证

> 使用 $export-buyer-discovery。继续现有批次，不新建名单。优先补公司的产品/经营证据，再核现任采购角色。公司公共、销售和采购个人联系方式分开，没有确证就留空。

## 输出如何阅读

[虚构结构示例](../examples/sample-output.md)只说明如何呈现未知与分级。不是数据集，不用于开发联系。国家建议必须在真实执行时查当前证据，邮箱和WA应逐项核归属与层级。
