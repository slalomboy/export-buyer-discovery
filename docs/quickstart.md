# 快速开始 / Quick start

## 环境

需要能够读取Skill文件的AI助手，以及执行联网任务时可用的搜索/浏览能力。表格输出可按环境用CSV或表格工具。没有安装agent-reach、sales-enablement或商业数据服务也可以使用本包；工具不足时输出缺口而非虚构结果。Skill本身不会提供登录、突破限制或购买数据。

## 安装和调用

使用根README的固定Tag克隆命令。它把仓库根目录作为Skill目录，SKILL.md无需移动。

路径已存在时先检查内容和VERSION，不能覆盖现有文件。Codex安装后重新打开会话，显式调用 `$export-buyer-discovery`。若界面未识别，可直接要求助手读取已安装目录的SKILL.md；客户端自动发现机制未作跨版本测试。

先填[输入卡](../templates/intake.md)，提供产品及工厂资料。第一步信息足够就继续市场比较；无需先有客户表。没有市场选择时让用户从建议中选择；已有按推荐继续授权则不重复询问。已有主表先映射字段，不建第二套名单。

## 检查包是否完整

如本机有Python 3.10+，在仓库内运行：

    python3 scripts/check_package.py

此脚本只检查本地结构、引用、版本和若干敏感模式，不联网、不采集、不修改客户信息。通过不代表获客准确或模型已经识别Skill。

## 验证范围

发布前进行临时目录克隆和包检查；不写入维护者现用全局Skill目录。公开后从固定Tag重新匿名下载、核对版本及运行检查。具体证据见仓库审计报告和维护者发布回执。未运行真实市场/联系人端到端研究，不声称效果。

## 续跑

说明“继续某批次”，给原主表及上次进度；从缺口继续，不重复第一步。数据或供货条件变动时只更新受影响步骤。删除或升级由用户另行处理，不用新的克隆命令强覆盖旧目录。
